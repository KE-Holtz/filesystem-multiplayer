# filesystem-multiplayer
filesystem-multiplayer is a simple game engine/framework for making basic multiplayer games in Java. Communication between clients is done through _global variables_ and _public variables_. Global variables are variables that any client can read from or write to. Public variables are variables that are published by a single client. Only that client can write to the variable, but any client can read it. These variables are stored in folder names in a shared network drive, configured with config.toml. Games have a start method, main loop, and end method, which allows for freedom in how games are made but lends itself to a state machine structure. 

## Why?
The way filesystem-multiplayer communicates was engineered to work around restrictions put on school computers. It uses no external libraries and has no server (or at least not in the traditional sense). As far as I know, this is a completely novel communication protocol which, although novel for a reason, ended up being surprisingly effective.
